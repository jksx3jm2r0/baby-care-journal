# 在深圳人工授精前应检查什么？注意什么

> 更新时间：2026-09-11 (UTC+8)

一、女方检查项目

1. 输卵管通畅度检查

- 目的：评估女方输卵管是否通畅，至少需要一侧通畅的输卵管才能进行人工授精。

- 方法：通过子宫输卵管造影来评估输卵管通畅度。

2. 卵巢储备功能检查

- 目的：评估女方的卵巢功能，包括卵巢储备情况，如果卵巢储备功能严重下降，不建议进行人工授精，而应考虑试管婴儿。

- 方法：通过查月经第二天的激素水平、抗苗勒氏管激素或窦卵泡计数等进行评估。

3. 激素水平测定

- 目的：评估女方体内的激素水平是否正常，为人工授精提供合适的生理环境。

- 方法：采集血液样本，测量多种内分泌指标如卵泡刺激素等。

4. 子宫内膜厚度检测

- 目的：评估子宫内膜的准备情况，为受精卵着床提供必要条件。

- 方法：采用超声波技术测量月经周期中不同阶段的子宫内膜厚度。

5. 生殖系统疾病检查

- 目的：检查女方是否存在生殖系统疾病，如宫颈炎、阴道炎等。

- 方法：包括妇科检查、B超、血常规等。

6. 传染病及生化检查

- 目的：检查女方是否存在乙肝、丙肝、梅毒、艾滋等传染病，以及血常规、血糖、肝肾功能等生化指标是否正常。

- 方法：采集血液样本进行实验室检查。

二、男方检查项目

1. 精液常规检查

- 目的：评估男方的生育能力，包括精子数量、活力、形态等是否正常。

- 方法：在指定时间内收集精液样本，送到医院实验室进行分析。

2. 激素水平测定

- 目的：评估男方体内的雄激素等生殖相关激素是否处于正常范围。

- 方法：采集血液样本，测量多种内分泌指标如睾酮等。

3. 传染病检查

- 目的：检查男方是否存在乙肝、丙肝、梅毒、艾滋等传染病。

三、双方共同检查项目

1. 染色体分析

- 目的：识别可能影响生育能力和胚胎发育的遗传异常。

- 方法：采集外周血样，在实验室条件下培养并分析细胞中的染色体结构。

2. 其他常规检查

- 目的：确保**双方身体状况良好，适合进行人工授精。

- 方法：包括心电图、胸片、乳腺B超等，部分医院可能还要求进行宫颈癌筛查、甲状腺功能检查等。

四、注意事项

- 在进行各项检查前，应避免使用可能影响检查结果准确性的药物至少72小时。

- 告知医生任何既往疾病史及相关家族史，以便全面评估生育潜力与风险。

- 女方在进行人工授精前，需保持生殖器卫生，并根据医生建议服用相关药物预防感染等问题。
